# Smart Marketplace Android App

Smart Marketplace is an Android application where users can buy and sell products easily.  
Users can register, add products, search items, chat in real time, and share product locations.

---

## 📌 Project Description

This project is developed as an academic Android application using modern Android technologies.  
The app focuses on user authentication, product management, real-time communication, and location-based features.

---

## ✨ Features

- User Authentication (Email/Password & Google Sign-In)
- Create, Read, Update, Delete (CRUD) Product Listings
- Search & Filter Products by name, category, price, and location
- Real-Time Chat using Firebase Firestore
- Google Maps Location Sharing
- QR Code Scanner
- Personal Notebook (Local storage using Room Database)
- REST API Integration for product display
- User Profile Update & Account Delete
- Secure logout functionality

---

## 🛠 Technologies Used

- **Programming Language:** Kotlin
- **UI:** Jetpack Compose
- **Architecture:** MVVM
- **Authentication:** Firebase Authentication
- **Database:** Firebase Firestore
- **Local Storage:** Room Database
- **Maps:** Google Maps API
- **Networking:** REST API
- **Tools:** Android Studio, Git

---

## 🧱 Project Architecture

The application follows **MVVM Architecture**:

- **Presentation Layer:** Jetpack Compose UI
- **ViewModel Layer:** Business logic & state management
- **Repository Layer:** Data handling
- **Data Layer:** Firebase Firestore & Room Database
